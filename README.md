# JPMorgan Chase & Co. - Software Engineering Job Simulation

[cite_start]This repository contains my work for the JPMorgan Chase & Co. Software Engineering Job Simulation, completed on the Forage platform in September 2025[cite: 169].

## About the Simulation

This job simulation provided a hands-on experience with the practical tasks and challenges faced by a software engineer at JPMorgan Chase & Co. The program involved setting up a development environment, integrating various financial data systems, and building a functional API to serve the data.

## Tasks Completed

During the simulation, I successfully completed the following technical tasks:

* [cite_start]**Project Setup**: Established the initial project structure and environment, ensuring all dependencies and configurations were correctly in place to begin development. [cite: 171]
* [cite_start]**Kafka Integration**: Implemented a data pipeline to interface with Kafka, a distributed event streaming platform, to handle real-time financial data feeds. [cite: 172]
* [cite_start]**H2 Integration**: Set up and connected the application to an H2 in-memory database, enabling efficient data storage and retrieval for analysis. [cite: 173]
* [cite_start]**REST API Integration**: Developed the necessary components to integrate a REST API, allowing the system to communicate with other services and data sources. [cite: 174]
* [cite_start]**REST API Controller**: Built a REST API controller to manage incoming server requests, process queries, and return the relevant financial data. [cite: 175]

## Skills Demonstrated

* [cite_start]**System Integration**: Successfully integrated multiple technologies including Kafka, H2 databases, and REST APIs. [cite: 172, 173, 174]
* [cite_start]**API Development**: Designed and implemented a REST API controller to handle client-server communication. [cite: 175]
* [cite_start]**Data Streaming**: Gained experience with Apache Kafka for processing real-time data streams. [cite: 172]
* [cite_start]**Database Management**: Utilized an H2 in-memory database for application data management. [cite: 173]
* **Financial Technology (FinTech)**: Applied software engineering principles to solve practical problems in a financial services context.
