# JPMorgan Chase & Co. - Software Engineering Job Simulation

This repository contains my work for the JPMorgan Chase & Co. Software Engineering Job Simulation, completed on the Forage platform in September 2025.

## About the Simulation

This job simulation provided a hands-on experience with the practical tasks and challenges faced by a software engineer at JPMorgan Chase & Co. The program involved setting up a development environment, integrating various financial data systems, and building a functional API to serve the data.

## Tasks Completed

During the simulation, I successfully completed the following technical tasks:

* **Project Setup**: Established the initial project structure and environment, ensuring all dependencies and configurations were correctly in place to begin development.
* **Kafka Integration**: Implemented a data pipeline to interface with Kafka, a distributed event streaming platform, to handle real-time financial data feeds.
* **H2 Integration**: Set up and connected the application to an H2 in-memory database, enabling efficient data storage and retrieval for analysis.
* **REST API Integration**: Developed the necessary components to integrate a REST API, allowing the system to communicate with other services and data sources.
* **REST API Controller**: Built a REST API controller to manage incoming server requests, process queries, and return the relevant financial data.

## Skills Demonstrated

* **System Integration**: Successfully integrated multiple technologies including Kafka, H2 databases, and REST APIs.
* **API Development**: Designed and implemented a REST API controller to handle client-server communication.
* **Data Streaming**: Gained experience with Apache Kafka for processing real-time data streams.
* **Database Management**: Utilized an H2 in-memory database for application data management.
* **Financial Technology (FinTech)**: Applied software engineering principles to solve practical problems in a financial services context.
